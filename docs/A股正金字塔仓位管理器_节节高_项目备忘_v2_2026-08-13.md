### 关键算法亮点（pyramid_atr_engine.py V4.1）

```
- 首笔 ATR 止损 = 基准价 - 3×ATR
- 自适应系数 k = clamp((ATR% - 1.5) / (5.0 - 1.5), 0, 1)
- 全仓止损区间 [5%, 8%]（随 k 自适应）
- 加仓间隔 主板 [10%, 12%]，科创/创业 [15%, 20%]（±20% 板加 5%-8%）
- 四档止盈 1.58~1.92 × 首笔价
- 高价降级手数比例：3 档 4:3:2，2 档 4:3
- 完整 A 股费率：佣金(最低5元)+ 过户费(双向) + 印花税(卖出)
- 每手：主板 100 / 科创板 200
```

### 4.4 自适应方案

- **uni-app 官方**：`rpx` 单位 750 设计稿基准自动适配宽度
- **高度 / 折叠屏**：用 `@media (orientation: landscape)` + 自定义断点 query（折叠屏展开检测不完美，但 90% 场景足够）
- **复杂场景**：用 `uni.getSystemInfo()` + `uni.onWindowResize` 监听折叠状态
- 进阶方案（可选）：`uni-app x`（UTS 语言）支持更精细的折叠屏 API

### 4.5 服务端怎么搞

**最简方案**：uniCloud（uni-app 自家的云开发），免运维、免备案、免域名

| 模块 | 实现 |
|---|---|
| 新闻采集 | 云函数定时触发 + 爬虫（参考 telegram_news.py 改 HTTP）|
| AI 研报解读 | 云函数 + 调用 DeepSeek/Qwen API |
| 持仓分析 | 云函数 + 直接搬 pyramid_atr_engine.py 的 Python 代码 |
| 数据存储 | uniCloud 数据库（基于 MongoDB）|

⚠️ 提醒：pyramid 算法用 Python 写的，**uni-app 客户端要把它翻译成 JS**（client-side 计算）或者放云函数（server-side 计算）。我建议：
- **算法放云函数**（保留 Python 一致性，客户端只传参接结果）
- **新闻/研报缓存放客户端**（减少 API 调用）
